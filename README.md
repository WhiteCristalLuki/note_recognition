# Note Trainer — тренажёр распознавания нот

Клиентское веб-приложение для тренировки чтения нот на скрипичном и басовом ключе.

## Стек

- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS** v4
- **Zustand** (persist → localStorage)
- **VexFlow 5** — отрисовка нотного стана
- **Tone.js** — воспроизведение звука
- **tonal.js** — работа с MIDI/нотами
- **lucide-react** — иконки

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Возможности

### Режимы
- **Чтение** — нота на стане → выбрать название (До4, Ре4…)
- **Запись** — название → выбрать позицию на стане
- **Смешанный** — чтение и запись вперемешку

### Система уровней
Три части (все уровни доступны сразу):

1. **Скрипичный** (1.1–1.9) — Соль3–Си4 → До5–До6 → Ми3–До6  
2. **Басовый** (2.1–2.18) — по группам октав, затем комбинации, финал Соль1–Ми4  
3. **Оба ключа** (3.1–3.9) — объединённые диапазоны

Внутри блока: **чтение → запись → смешанный**.  
Обычный уровень: **20 нот**. Финалы **1.9 / 2.18 / 3.9**: **50 нот**.  
Уровень **пройден**, только если все ответы верны. Прогресс в localStorage.

### Кнопки ответа
- Скрипичный: Ми3–До6  
- Басовый: Соль1–Ми4  
- Оба: Соль1–До6  
Строки по октавам; октава проверяется (До4 ≠ До5).

### Custom
Свободная настройка вне системы уровней.

### Игровой процесс
- VexFlow, звук (Tone.js), streak, точность
- экран результатов, «следующий уровень» после ideal clear
- светлая / тёмная / системная тема

## Архитектура

```
src/
  components/
    game/          # GameScreen, HUD, кнопки, Writing-опции
    layout/        # Header
    results/       # ResultsScreen
    setup/         # Home + CustomSettings
    staff/         # NoteStaff (VexFlow)
  hooks/           # theme, keyboard, timer
  lib/             # notes, generator, audio, vexflow, presets
  stores/          # settings, game, stats (Zustand)
  types/
```

MIDI: **C4 = 60**. Генерация нот — равномерная из выбранного пула.
